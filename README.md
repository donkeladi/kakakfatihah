# Surat Untuk Kakak

Landing page hari lahir (statik: HTML/CSS/JS). Buka `index.html` atau jalankan `python3 -m http.server`.

## Untuk diganti
- **Isi surat**: `index.html`, bahagian `#letter`
- **Gambar**: gambar dalam `images/1.jpg` hingga `6.jpg`, dan gambar keluarga `images/f1.jpg` hingga `f11.jpg` (tukar kapsyen dalam `index.html`)
- **Muzik**: `audio/lagu.mp3` (Brothers - Teman Sejati), main automatik bila kakak tekan "Buka"
- **Warna**: pembolehubah `:root` di `style.css`
